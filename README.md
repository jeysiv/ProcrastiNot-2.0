# ProcrastiNot
ProcrastiNot is a task management web application that helps users organize tasks, track deadlines, and manage priorities. Built with PHP and MySQL, it applies data structures and algorithms such as BST, Linear Search, Bubble Sort, and Queue to make task management more organized and efficient.

Completed tasks are hidden from the current task list and available from the completed-tasks button at the bottom left. Reopen a completed task to return it to the current list.
